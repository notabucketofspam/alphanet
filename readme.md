# alphanet

what's in the box:

- [**base**](./base/): some sloppo code to interface with the Alpha Director via Alpha Protocol 1.0
- [**cmake**](./cmake/): copy-pasta from another repo
- [**esp/slopathon_5k**](./esp/slopathon_5k/): replace the control board on the Alpha Director with an Espressif ESP32
  - the code here is also slop-flavoured
- [**junk**](./junk/): some notes I took while trying to reverse-engineer the actual LED communication pattern on the Alpha Director
  - with another guest appearance by sloppo
- [**lab6**](./lab6/): pain
- [**zapper**](./zapper/): nodejs program to take a raw video stream from OBS and send it to the `slopathon_5k` ESP32
  - slightly less slop this time
